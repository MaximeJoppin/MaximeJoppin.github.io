Module PrestaShop

Custom CSS & JS

Module PrestaShop pour éditer le CSS et le JavaScript de chaque page depuis le back-office.

Rôle
Conception et développement
Cible
PrestaShop 1.7 / 8
Statut
Utilisé sur la boutique MaxTCG

Technologies

  • PHP
  • PrestaShop
  • Smarty
  • SQL
  • CSS

Compétences BUT

  • C1 Réaliser un développement d’application
  • C4 Gérer des données

En bref

Un éditeur intégré au back-office : un CSS et un JS « global » plus un par type de page (accueil, produit, panier…), injectés automatiquement dans l’en-tête.

Fonctionnement

  • 24 types de pages front-office reconnus, chacun avec son entrée CSS et JS activable.
  • Au rendu, le module lit le contrôleur courant et injecte d’abord le code global puis celui de la page, dans cet ordre.
  • Requêtes protégées (pSQL), onglet ajouté dans le menu Design.
